# content — 인박스 추천 자료

사용자가 목표를 세우면 그 카테고리에 맞는 참고 자료가 인박스에 들어간다(BE #171).
여기 있는 `.md` 파일은 **가공 없이 사용자 화면에 그대로 렌더된다** — 프롬프트가 아니라
최종 출력물이다.

```
content/<category>/<slug>.md
```

- `<category>` = Goal 카테고리 9종 중 하나 (`registry.SUPPORTED_CATEGORIES`).
  화이트리스트에 없는 폴더는 **조용히 무시**된다(warning 만 남는다).
- `<slug>` = 파일명(확장자 제외). `^[a-z0-9][a-z0-9-]{2,47}$` — 소문자 영숫자와 하이픈만.
  `GET /inbox/resources/{slug}` 의 경로 값이자 전역 유일 키다(카테고리를 가로질러 유일).

`prompts/` 와 달리 **버전 접미사(`.v1.md`)가 없다.** 프롬프트는 파일을 떨구면 `latest()`
가 갈아타는 A/B 설계지만, 여기는 사용자가 읽는 글이라 그 성질이 위험하다. 자료를 고치려면
그 파일을 고친다.

## frontmatter

파일 맨 첫 줄부터 `---` 로 열고 닫는다. **평평한 `key: value` 4줄만** 받는다.

```markdown
---
slug: exercise-plan-that-bends
title: 빠지는 날까지 계획에 넣기
category: health
summary: 주 3회를 '꼭 1회 + 되면 2회'로 나눠 두면 하루 걸러도 계획이 안 흔들려요.
---

# 빠지는 날까지 계획에 넣기

...
```

- 4개 키 **전부 필수**. 중첩·리스트·멀티라인·따옴표·주석은 지원하지 않는다.
- `slug` 는 파일명과, `category` 는 폴더명과 문자 단위로 같아야 한다. 어긋나면 그 파일은
  등록되지 않는다.
- `title` 은 **본문 첫 `# ` 제목과 완전히 같은 문자열**이어야 한다. FE 가 첫 H1 을 헤더
  제목과 대조해 같을 때만 본문에서 덜어내므로, 마침표 하나만 달라도 제목이 두 번 뜬다.
- 응답에 실리는 `markdown` 은 **frontmatter 를 걷어낸 본문**이다. FE 는
  `remark-frontmatter` 를 쓰지 않아 머리말이 그대로 나가면 화면이 깨진다.

길이 예산(모바일 375px 기준): `title` ≤ 16자, `summary` ≤ 45자, 본문 900~1,300자.

## 마크다운 제약 — raw HTML 금지

FE 뷰어는 `react-markdown` + `remark-gfm` 만 쓰고 **`rehype-raw` 를 의도적으로 뺐다**
(XSS 원천 차단). 그래서 raw HTML 은 렌더되지 않고 **텍스트로 그대로 노출된다.**

쓸 수 있는 것:

- `#` / `##` / `###` 제목, 문단, `-` 목록, `1.` 목록
- `**강조**`, `>` 인용, `---` 구분선, `[텍스트](URL)` 링크
- GFM 표, 인라인 `` `코드` ``

쓰지 말 것:

| 쓰지 말 것 | 이유 |
| --- | --- |
| 모든 raw HTML (`<br>`, `<div>`, `&nbsp;`) | 렌더 안 되고 태그가 그대로 보인다 |
| `####` 이상 | 컴포넌트 맵에 없어 앱 타이포와 따로 논다 |
| 체크박스 `- [ ]` | 스타일 없는 기본 체크박스가 불릿과 겹친다 |
| 각주 `[^1]`, 이탤릭 `*…*` | 스타일 없음 / 한글 가독성 나쁨 |
| 이미지 `![]()` | 호스팅 자산이 없고 외부 URL 은 프라이버시 위험 |
| 코드 펜스 | 이 자료에 코드 블록은 의미적으로 틀리다 |

표는 자료당 1개, 2~3열 × 5행 이내. 표 헤더는 줄바꿈되지 않으므로(`nowrap`) **6자 이내**로.
외부 링크는 기본 0개 — 앱을 벗어나고, 검증된 출처 목록이 레포에 없다.

## 문체

톤 잠금은 **"Be on your side, not on your case"** (AGENTS.md §1). 이 자료는 회복 카드와
나란히 놓이므로 말투가 갈리면 안 된다.

- 존댓말 청유·권유형으로 통일: `~해요`, `~해볼까요`, `~하면 돼요`.
  반말·명령형·평서 단정형(`~한다`) 금지.
- **원인은 사람이 아니라 상황에.** `의지가 약해서` (X) / `이 계획이 좀 컸던 것 같아요` (O).
- **금지어 사전**(`safety/banned_words.py`)에 걸리는 표현을 쓰지 않는다:
  `실패` `또 못` `안 됐` `못했` `왜 안` `다시 실수` `게으르` `한심` `패배` `포기`.
  한국어로 자연스럽게 튀어나오니 주의 — `운동을 못했어도` → `운동을 하지 않은 날에도`.
  운동 용어 `실패 지점(muscle failure)` 도 걸린다 → `더 이상 안 올라가는 지점`.
- **성과 압박 프레이밍 금지**: 연속 N일·스트릭·작심삼일·핑계·의지·`무조건`.
  이 앱이 재는 건 연속 달성이 아니라 회복률이다.
- **수치는 하한 예시로만.** `주 3회는 해야` (X) / `5분` `한 세트` `계단 한 층` (O).
  앱의 최소 단위(5·15·20·30분)와 어긋나지 않게, 항상 더 줄여도 된다는 여지를 남긴다.
- **의학 영역을 건드리지 않는다**: 통증·부상·재활·심박수·세트/렙 처방·체중 목표·식단·
  보충제·효능 주장. 몸 상태가 변수인 지점은 처방이 아니라 선택지로
  (`무리가 되면 산책으로 바꿔도 좋아요`).
- **내부 enum·전략 코드를 노출하지 않는다**(`NANO_STEP`, `failure_type` 등). 대신 앱이 쓰는
  한국어 라벨 그대로: `시간이 부족했어요`, `에너지가 낮았어요`, `계획이 너무 컸어요`.
- 자동 적용을 암시하지 않는다 — 이 제품은 전부 [수락/수정/거절] HITL 이다.
- 승격 유도 금지 — 자료 카드에는 [할 일로]/[목표로] 버튼이 없다([열기]·[보관]만).
- 한국어만 (AGENTS.md §1).

## 테스트가 고정하는 것

`tests/test_content_registry.py` 가 커밋된 모든 자료에 대해 검사한다. 새 자료를 추가하면
자동으로 검사 대상에 들어간다.

- frontmatter 4필드 존재 · `slug` == 파일명 · `category` == 폴더명
- 본문 첫 줄이 `# {title}` 과 정확히 일치
- 금지어 스캔 0건
- raw HTML · `####` 이상 · 체크박스 · 각주 0건
- 디스크의 모든 `.md` 가 실제로 등록됐는가 (규격 미달로 조용히 탈락한 파일 검출)

금지어 스캔은 필요조건일 뿐이다 — 사전이 어간 부분문자열 매칭이라 활용형(`게으른`,
`게으름`)은 통과한다. **사람 리뷰가 여전히 필요하다.**
